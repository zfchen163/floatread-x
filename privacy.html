浮阅X 隐私政策

最后更新：2026-10-08 · 产品名：浮阅X（FloatRead X）

浮阅X 是一款在本机浏览器中运行的扩展，用于在网页版 X（x.com / twitter.com）以双栏浮层阅读帖子。本扩展不运营后端服务器。

1. 我们处理哪些数据

  • 读取当前已登录 X 标签页中的帖子、评论、作者与媒体信息，仅用于浮层展示。
  • 使用浏览器中的 X 登录会话，向 X 官方接口完成点赞、转发、收藏、关注、回复、翻译等操作。
  • 使用 Chrome storage 保存本地偏好（开关、主题、字号、护眼时段等）。不保存登录凭据。
  • 「稍后读」仅在本机 storage.local 保存你主动加入的链接与短摘要，可随时清空，不上传第三方。

2. 权限用途

权限用途
storage保存本地偏好设置
x.com / twitter.com注入浮层，并用当前登录会话读写帖子

不申请 Cookie、tabs、webRequest、declarativeNetRequest、剪贴板或全站访问权限。

3. 我们不会做什么

  • 不会把 X 内容、Cookie、登录凭据或 CSRF 发给第三方服务器。
  • 不会把会话凭据写入扩展存储或日志。
  • 不会加载远程扩展代码；视频播放组件随扩展本地打包。

4. 第三方

账号相关请求由 X / Twitter 处理，并受其服务条款与隐私政策约束。

5. 删除数据

卸载扩展即可删除本机偏好设置。你在 X 上产生的内容仍由 X 账号体系管理。

6. 联系

请通过 Chrome 应用商店「浮阅X」扩展页的支持渠道联系开发者。
