## 详细说明

```
浮阅X：点开帖子不跳转，双栏浮层读完再刷。

在网页版 X（x.com）刷时间线时，点一条帖子通常会跳进详情页，回来后位置也容易丢。浮阅X 在当前页面弹出左右双栏浮层：左边看原帖，右边读评论，关掉后仍停在原来的刷帖位置。

【核心能力】
• 双栏阅读：原文与评论同屏，各自独立滚动
• 完整内容：图片、视频、引用帖、网站卡片、X 长文
• 基础互动：点赞、转发、收藏、复制链接、纯文字回复
• 自动翻译：外语帖子可默认显示中文（可关）
• 夜间护眼：暖色低蓝光主题，减轻夜间眩光
• 定时护眼：自定义时段，跟随 X 主题时自动切换
• 专注模式：一键只看正文，沉浸读长文
• 字号调节：小 / 标准 / 大 / 更大

【隐私】
仅申请 storage 与 X 站点权限。帖子与登录会话只在本机处理，不发往扩展作者服务器。详见隐私政策。

【说明】
本扩展为非官方社区工具，与 X Corp. 无关。X 内部接口若大幅变更，功能可能需要后续更新。
```

## 权限理由（审核常见问答）

**为什么需要 storage？**  
保存用户偏好：是否启用浮层、翻译、主题、字号、护眼时段、专注模式。不存帖子内容。

**为什么需要访问 x.com / twitter.com？**  
只在 X 网页注入浮层阅读器，并用用户已登录会话读取帖子与完成互动。不访问其他网站。

**是否出售数据 / 远程代码？**  
否。无远程代码、无自建后端、无广告追踪。

## 商店素材清单

已生成目录 `chrome-store/`：

- `promo-marquee.png`：宣传图参考（建议再按商店尺寸精修）
- `privacy.html`：隐私政策页（需托管为可公网访问的 URL）
- `LISTING.md`：本文案

还需要你准备（商店硬性要求）：

1. **小图标**：已由构建生成 `dist-extension/icons/icon128.png`
2. **截图至少 1 张**：1280×800 或 640×400，建议截真实浮层界面 3–5 张
3. **隐私政策 URL**：把 `privacy.html` 放到 GitHub Pages / 个人站点后填入后台
4. **开发者账号**：Chrome Web Store 一次性注册费（通常 $5）

## 上传包

运行：

```bash
cd floatread-x   # 或当前项目目录
npm run pack:store
```

得到 `chrome-store/floatread-x-1.0.0.zip`，在 [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole) 新建商品并上传。
